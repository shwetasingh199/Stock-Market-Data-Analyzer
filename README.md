# 📈 Stock Market Data Analyzer

A complete **Python-based financial analytics dashboard** built using **Streamlit, Pandas, Plotly, and Yahoo Finance API** for real-time stock market analysis, visualization, and risk analysis.

This project helps users analyze:
- stock price trends
- moving averages
- volatility
- RSI
- Bollinger Bands
- daily returns
- cumulative returns
- trading volume

It provides an interactive dashboard similar to modern FinTech analytics platforms.

---

# 🚀 Project Overview

The **Stock Market Data Analyzer** is an industry-oriented financial analysis project that fetches real-time stock market data using Yahoo Finance and performs technical analysis with interactive visualizations.

The dashboard allows users to:
- Analyze stock performance
- Study price trends
- Understand market volatility
- Visualize trading indicators
- Generate downloadable reports

# ⚙ Installation Guide

## Step 1 — Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/Stock-Market-Data-Analyzer.git
```

---

## Step 2 — Open Project Folder

```bash
cd Stock-Market-Data-Analyzer
```

---

## Step 3 — Install Requirements

```bash
pip install -r requirements.txt
```

---

# ▶ Run Project

```bash
streamlit run streamlit_app/app.py
```
